# Yawrd development instructions

- This is the independent Yawrd development repository.
- Do not access, copy, or import proprietary Keelbase source code or other private repositories.
- Do not read credential stores, private keys, wallet files, environment secrets, or unrelated user directories.
- Do not install dependencies, deploy contracts, execute wallet transactions, push branches, or publish code without explicit authorization.
- Work in small, testable changes; report modifications and test results.
- Keep public-facing contract integration separate from Keelbase proprietary implementations.
- Do not assume the tech stack has been selected.
- Obtain human approval before merges or irreversible operations.

## Product Language

- A Yawrd is the complete project space, not merely its underlying DAO.
- In user-facing copy, use Yawrd vocabulary and approachable explanations instead of blockchain terminology. Provisional terms, pending product design approval: Open a Yawrd, Project Funds, Stewards, Project Rules, Crew Members, Reward Requests, and Approve Rewards.
- DAO, Sputnik, factory, proposals, and smart contracts remain appropriate in code, integration documentation, and developer-facing material.
- Clearly disclose important wallet actions, costs, and approval requirements.
